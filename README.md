# IBCS Card

一个面向 Microsoft Power BI 的多 KPI 卡片自定义视觉对象。视觉语言参考 IBCS 的信息密度与差异语义，包含响应式卡片、实际/计划/去年同期差异、微型趋势图、卡片与行布局、同步刻度、聚焦模式、备注、选择、上下文菜单和拖拽排序。

> 本项目为独立实现，不包含 Zebra BI 的代码、商标或素材。

## 下载与安装

从 [Releases](https://github.com/muxiaoqi007/ibcs-card/releases/latest) 下载最新的 `.pbiviz` 文件，然后在 Power BI Desktop 中选择“获取更多视觉对象 > 从文件导入视觉对象”。

## 主要功能

- 响应式多 KPI 卡片与行布局
- 实际值、去年同期、计划和预测数据
- 相对差异与绝对差异展示
- 面积图、折线图、瀑布图和差异图
- 按主值、差异或标题排序
- 卡片选择、交叉筛选、聚焦模式和备注
- 中文格式设置及完整的元素样式控制

## 本地预览

```powershell
npm install
npm run demo
```

浏览器打开 `http://127.0.0.1:5173/`。

## 生成 Power BI 视觉对象

```powershell
npm run package
```

生成的 `.pbiviz` 文件位于 `dist/`，可从 Power BI Desktop 的“获取更多视觉对象 > 从文件导入视觉对象”导入。

## 字段映射

- `趋势类别`：月份、日期等趋势维度
- `指标分组`：KPI 名称
- `实际值`：实际值，最多四个度量值
- `去年同期`：去年同期或基准值
- `计划`：计划值
- `预测`：预测值
- `工具提示`：附加提示字段
- `备注`：动态备注
